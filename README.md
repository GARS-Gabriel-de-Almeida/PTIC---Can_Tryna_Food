# Can Tryna Food?

## Sobre o projeto

O **Can Tryna Food?** é um projeto acadêmico desenvolvido para o curso Técnico em Desenvolvimento de Sistemas da ETEC de Cidade Tiradentes, com o objetivo de propor uma solução digital para os problemas de filas, tempo de espera e controle de produtos na cantina escolar.

A proposta consiste em um sistema que permite aos alunos consultar o cardápio, realizar pedidos antecipadamente, agendar a retirada dos produtos e efetuar pagamentos. Para os funcionários e gerentes, o sistema prevê funcionalidades de gerenciamento de estoque, controle de pedidos, cadastro de funcionários e consulta de relatórios.

## Principais funcionalidades propostas

* **Cliente:** consultar o cardápio, fazer pedidos, agendar a retirada e realizar pagamentos.
* **Funcionário:** gerenciar o estoque, acompanhar pedidos e registrar entregas.
* **Gerente:** cadastrar funcionários e consultar relatórios.

## Desenvolvimento do projeto

Durante o desenvolvimento, foram elaborados documentos de análise e modelagem do sistema, incluindo:

* Fluxogramas dos processos;
* Diagrama de caso de uso;
* Descrições dos casos de uso;
* Matriz de rastreabilidade;
* Regras de negócio;
* Requisitos funcionais e não funcionais;
* Protótipos de baixa e alta fidelidade das interfaces.

## Recursos utilizados
